# FOCIVO WEB PROJECT STRUCTURE

Status: FOUNDATION LOCKED / CONTENT PHASES PENDING

## Visual base

The current Home page is the accepted visual base. WEB-001 derives the reusable visual system from that direction; it does not redesign the Home concept.

## Core information principle

FOCIVO.COM must be complete without feeling heavy. Information is separated by purpose, ordered clearly and revealed progressively. Visitors should be able to find what matters without searching through unrelated content.

## Public knowledge principle

General product knowledge, feature explanations, Learn/Academy and general Support remain available without LOGIN. LOGIN exists as a real website area, but its personal-support/recovery mechanism is a separate future design phase.

## Released-only rule

No planned project, feature or version is promoted as public product news before it is complete, tested, functional and accepted. Unfinished route shells are development structure only and remain noindex until their dedicated phase is complete.

## Route foundation

- `/` — Home — accepted visual base
- `/about/` — ΠΟΙΟΙ ΕΙΜΑΣΤΕ / ABOUT FOCIVO
- `/how-it-works/` — How It Works
- `/features/` — Features
- `/learn/` — Learn / Academy
- `/support/` — Support
- `/ideas/` — Help Shape FOCIVO / User Voice
- `/whats-new/` — What’s New — released-only
- `/security/` — Security & Protection
- `/get-focivo/` — Get FOCIVO
- `/login/` — LOGIN

Each category will be designed and completed separately after the project foundation is stable.
