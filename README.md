# FOCIVO WEBSITE

Official website source for FOCIVO.

## Locked brand rules

- The brand name is always exactly `FOCIVO`.
- `FOCIVO` is never translated, respelled or altered.
- The website supports English and Greek through the `EN / ΕΛ` switch.
- Greek copy is meaning-first natural Greek, not word-for-word machine translation.

## Website files

- `index.html` — landing page and semantic structure.
- `styles.css` — premium responsive visual system for desktop, tablet and mobile.
- `app.js` — bilingual EN / ΕΛ content and mobile navigation.
- `assets/focivo-logo.webp` — official primary FOCIVO logo.
- `assets/focivo-symbol.webp` — official transparent FOCIVO symbol.
- `assets/windows-icon.webp` — Windows application icon.
- `assets/mobile-icon.webp` — Mobile application icon.
- `assets/favicon.ico` — browser favicon.

## Product status represented on the site

- FOCIVO Windows Desktop is the primary application.
- FOCIVO Mobile is explicitly shown as in development until production testing and acceptance are complete.

The website intentionally avoids claims that are not yet production-verified.
